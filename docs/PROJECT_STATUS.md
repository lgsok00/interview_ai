## 문서 갱신 규칙

- 현재 상태·다음 작업·최신 검증·Git 기준점은 이 문서에서 관리한다.
- 기능·정책·테스트 상세는 해당 문서에 반영하고 중요한 변경은 변경 이력에 날짜와 함께 추가한다.

- 과거 결과는 삭제하지 않는다. 과거 기록과 최신 상태가 다르면 이 문서의 최신 상태를 기준으로 읽는다.
